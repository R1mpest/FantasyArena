# Fantasy Arena

2D-игра в жанре roguelite (survivors-like) на Godot 4, курсовая работа по ТРПО.

Персонаж сам стреляет по ближайшим врагам, волны со временем становятся сильнее.
С врагов падает опыт, и на каждом новом уровне игрок выбирает одну из трёх карт:
характеристику героя, новое оружие или прокачку уже взятого оружия.

Оружие: магический снаряд (стартовое), магические сферы вокруг героя,
огненный дождь (взрывы по площади), пылающая аура.

У персонажа есть личные навыки (3 уровня), они выпадают только ему.
Волшебник (`data/characters/wizard/`): «Резонанс» — каждый N-й снаряд взрывается,
«Мана-щит» — поглощает урон и восстанавливается без попаданий,
«Поток» — убийства ускоряют атаку, урон сбрасывает бонус.

## Запуск

Нужен Godot 4.7 (рендер Compatibility, подходит и без Vulkan).

```sh
godot --path .        # игра
godot -e --path .     # редактор
```

Управление: WASD, стрелки или геймпад; выбор улучшения — мышью или клавишами 1–3; Esc — пауза; R — заново после поражения.

Настройки (главное меню и пауза): режим окна и разрешение, громкость (общая, музыка, эффекты),
прицеливание — автоматически в ближайшего врага или по направлению мыши (на геймпаде — правым стиком).
Хранятся в `user://settings.cfg`.

## Структура

| Папка | Что лежит |
|---|---|
| `autoload/` | `SaveManager` (настройки), `EventBus` (глобальные сигналы), `GameState` (таймер, уровень, убийства), `Transition` (смена сцен) |
| `scenes/` | главное меню, сцена забега, игрок, враги, оружие, кристаллы опыта, интерфейс и карты прокачки |
| `systems/` | спавн волн, опыт, выбор улучшений, формулы баланса |
| `data/` | баланс в ресурсах `.tres`: враги, карты прокачки, персонажи и их личные навыки правятся без изменения кода |
| `assets/` | спрайты 0x72 DungeonTileset II (CC0), лицензии в `assets/LICENSES.md` |
| `tests/` | модульные тесты формул и автопрогон забега |

## Проверки

```sh
godot --headless --path . --import
godot --headless --path . res://tests/test_formulas.tscn
godot --headless --fixed-fps 60 --path . res://tests/autoplay.tscn -- --seconds=180
```

Автопрогон бегает по кругу, сам выбирает карты и в конце печатает итог забега.
Ключи: `--give=orbs,meteor,aura` — выдать оружие на старте, `--weapons` — брать карты оружия,
`--screenshot=файл.png` — снимок в конце (нужно окно, не `--headless`).
Замер производительности (требование Н1): на арене всё время держится N врагов, у героя всё оружие.

```sh
godot --headless --fixed-fps 60 --path . res://tests/bench.tscn -- --enemies=300 --seconds=20
```

Снимок главного меню: `godot --path . res://tests/menu_shot.tscn -- --screenshot=menu.png`.
CI (`.gitea/workflows/ci.yml`) запускает обе проверки на каждый push.
