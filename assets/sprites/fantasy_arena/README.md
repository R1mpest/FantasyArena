# Fantasy Arena — ассет-пак

69 спрайтов в едином стиле: пиксель-арт на сетке 16×16, тёмная обводка `#241a2c`,
общая палитра из 40 цветов (`palette.png`). По стилю совместим с 0x72 DungeonTileset II.
Все спрайты нарисованы для проекта (собственная графика автора), сторонних ассетов внутри нет.

Обзор всего пака — `preview.png`.

## Состав

| Папка | Что внутри | Размер |
|---|---|---|
| `items/16`, `items/32` | 15 предметов: boots, heart, magnet, power, ring_of_life, hourglass, lens, plate_armor, quiver, storm_boots, anchor, blood_crystal, glass_cannon, phoenix_feather, cursed_idol | 16 и 32 px |
| `skills/16`, `skills/32` | Навыки мага: resonance (Резонанс), mana_shield (Мана-щит), flow (Поток) | 16 и 32 px |
| `weapons/16`, `weapons/32` | Иконки 9 оружий: magic_bolt, fire_rain, chain_lightning, orbs, aura, frost_bell, cursed_skull, throwing_axe, holy_water | 16 и 32 px |
| `projectiles/` | Спрайты на арене: магический снаряд (2 кадра), сфера, метеор, секира, склянка, лужа святой воды (2 кадра), черепа: кусающий, горящий, проклятый (по 2 кадра) | 16 px, лужа 24×12 |
| `pickups/` | Кристаллы опыта 4 номиналов, наковальня, «+» лечения | 8 и 16 px |
| `effects/` | Взрыв (5 кадров), искра попадания (3), кольцо мороза (3) | 16, 8, 32 px |
| `ui/` | Рамки слотов (класс, общее, предмет, навык), панели для 9-slice, звезда навыка, метка опасности (2 кадра), стрелка у края экрана | 8–24 px |

32-пиксельные версии — те же спрайты, увеличенные ×2 без сглаживания, для карточек улучшений.

## Как подключить в Godot

1. Скопировать папку в `res://assets/sprites/fantasy_arena/`.
2. Фильтрация уже выставлена на Nearest в `project.godot` (`default_texture_filter=0`), спрайты будут чёткими.
3. Анимации — `SpriteFrames` из кадров `_f0`, `_f1`, … Рекомендуемая скорость:

| Анимация | Кадров | FPS | Цикл |
|---|---|---|---|
| magic_bolt | 2 | 8 | да |
| skull_chomp | 2 | 6 | да |
| skull_flaming, skull_cursed_flaming | 2 | 10 | да |
| holy_puddle | 2 | 4 | да |
| explosion | 5 | 15 | нет |
| hit_spark | 3 | 20 | нет |
| frost_ring | 3 | 12 | нет (или одно кольцо + `scale` в коде) |
| warning_circle | 2 | 4 | да, мигание |

4. Летящие спрайты нарисованы направленными вправо — поворачивать по `velocity.angle()`.
5. Панели `panel_9slice*.png` (24×24) — для `NinePatchRect`, отступы патча **4 px** со всех сторон.
6. Кристаллы опыта по номиналам: 1–4 синий, 5–19 зелёный, 20–99 золотой, 100+ красный.
7. Элитные враги и золотой гоблин — существующие спрайты 0x72 с `modulate`, отдельные файлы не нужны.

## Как дорисовать новое в том же стиле

- Брать цвета только из `palette.png`; обводка — `#241a2c`.
- Свет падает слева сверху: блик (`#f4f4f4`) в левом верхнем углу, тень — справа снизу.
- Размер иконки 16×16, сам предмет занимает примерно 12×12 по центру.
- Исходник всех спрайтов — `source/build_pack.py`: каждый спрайт задан сеткой символов,
  символ = цвет палитры. Правишь сетку, запускаешь `python3 build_pack.py` — пак пересобирается.
